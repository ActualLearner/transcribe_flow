# TranscribeFlow

## 1. Project Goal

To build a transcription website that accepts audio & video files, transcribes them, then allows editing to the generated text, as well as downloading in subtitle & text format. An AI summary of the text is also available.

---

### Functional Requirements

- File Upload
- Transcribe File
- Edit text
- Download in subtitle & text format.
- AI summary of file.

## 2. Functional Requirements

### File Upload

Accept video & audio files.

- **Acceptance Criteria:**
  - Files larger than 50mb should be rejected.
  - "Real-time Progress Bar" is displayed during the upload phase.

### File transcription

Transcribe file into text/subtitle format.

- Acceptance Criteria:
  - User can download/view transcribed text.

### Interactive Editor

Allow viewing/editing of the text.

- **Acceptance Criteria:**
  - Clicking save should save the text & update the subtitles to match.
  - Downloads are triggered via the browser without page reloads.

### Download Transcription

Download transcription in text & subtitle.

- Acceptance Criteria:
  - User can download a subtitle file of the transcription.
  - User can download a .txt file of the transcription

### AI Summary

Summary of the audio transcription generated by an AI.

- Acceptance Criteria:
  - User can read an AI summary of the transcription by pressing a button.

---

## 3. Feature Flows

### File Upload

1. User uploads files.
2. System displays a loading indicator.
3. When system completes transcription, it displays an ai summary button, a text editor for the transcription as well as download buttons for txt & srt formats.

### 3.1 Download File

3.1.1 User clicks download subtitle file.
3.1.2 Download starts.

### 3.2 AI Summary

3.2.1 User clicks summarize.
3.2.2 System displays loading.
3.2.3 System displays the summary after loading is complete.

### 3.3 Edit transcription

3.3.1 User clicks edit transcription
3.3.2 System loads transcription in text area.
3.3.3 User clicks save.
3.3.4 System updates transcription files.

## 4. Non-Functional Requirements (NFRs)

---

## 5. Out of Scope

- **Cloud Hosting:** AWS deployment is for the "next" project.
- **Live Recording:** No browser-based microphone recording (Upload only).
- **Large Files:** No files over 50MB (to avoid killing local CPU/RAM during AI processing).
